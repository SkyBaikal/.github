### 🌊 About Us

SkyBaikal 是一个开放的创作型组织。我们相信：

- 💡 **想法不分大小** — 从一行脚本到完整产品，都值得一个仓库

- 🌌 **长期主义** — 像贝加尔湖一样深，像星空一样远
